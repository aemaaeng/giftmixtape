# 제품

노래 5곡을 골라 카세트테이프를 만들고, 링크로 친구에게 선물하는 웹 서비스.
받은 사람은 테이프를 넣고 버튼을 눌러 재생한다.

## 이미 정한 것

바꾸려면 구현 전에 먼저 물어본다. 결정 이유는 노션 결정 기록 DB에 있다.

- 테이프 하나에 **딱 5곡**. 더 넣는 기능은 만들지 않는다 (필요해지면 B면으로 해결)
- **로그인 없음**
- **공유 링크를 발급하면 테이프가 확정된다**
  - 발급 전(곡 고르기·꾸미기 중)에는 자유롭게 고칠 수 있다. 이 상태는 브라우저에만 있고 서버에 저장하지 않는다
  - 편집 중인 테이프는 브라우저에 임시 저장해서, 새로고침하거나 모바일에서 다른 앱을 다녀와 페이지가 다시 로드돼도 이어서 만들 수 있다
  - "링크 만들기"를 누르는 순간 서버에 저장되고 링크가 발급된다. 이후에는 곡·이름·라벨을 수정할 수 없다
  - 바꾸고 싶으면 새 테이프를 만든다 (새 링크가 발급된다)
- 곡 사이는 테이프처럼 재생: 짧은 공백 + 테이프 잡음, 다음 곡은 페이드인
- 곡마다 원곡 링크: Apple Music 곡 링크 + Spotify·YouTube Music 검색 링크 (API 연동 없음)
- 링크 미리보기 제목은 "OO님이 OO님에게 선물한 노래"
- 받는 화면에서 테이프를 인스타 스토리 비율(9:16) 이미지로 저장할 수 있다
- 실시간 AI 호출 없음

## MVP 범위

1. 곡 고르기: 검색해서 5곡 담기, 순서 바꾸기
2. 테이프 꾸미기: 라벨 색, 테이프 제목·받는 사람·보내는 사람 입력
3. 공유 링크 만들기
4. 받는 화면: 카세트를 넣고 재생
5. 이미지로 저장하기 (일정이 밀리면 가장 먼저 뺀다)

MVP에 없는 기능(플레이리스트 만들기, 답장 테이프, 모아보기, 삭제 등)은 요청받기 전에 만들지 않는다.

## 미정

- 라벨 색을 앨범 커버에서 자동 추출할지 (노션 결정 기록 "검토 중")
- 브랜드 이름 (작업명·도메인은 giftmixtape)
